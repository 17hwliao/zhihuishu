# API 与中转站配置

本说明针对 **2.5.7**。使用本版 Release 的 `zhihuishu-mastery.user.js` 更新油猴后刷新智慧树页面，展开“API 与重试设置”。默认分支源码与当前附件一致；历史 v1.0.0 附件保留，不包含近期修复。

## DeepSeek 官方

1. 接口类型选择“DeepSeek 官方”。
2. 填写 DeepSeek 官方平台创建的 API Key，模型默认 `deepseek-flash`；也可填写账号实际可调用的模型 ID。
3. 保存后点击“测试 API 连接”。连接检测与实际答题使用同一套已保存配置。

官方请求地址固定为 `https://api.deepseek.com/chat/completions`。Key 与地址分开填写，无需在 Key 前加 `Bearer`。

## OpenAI 兼容中转站

接口类型选择“OpenAI 兼容 / 自定义中转站”，依次填写服务商地址、该站签发的 Key、该站提供的模型 ID，再保存。模型名支持 `/`、`:` 等常见字符；必须使用服务商列出的实际模型 ID。

| 填写的地址 | 最终请求地址 |
| --- | --- |
| `https://relay.example.com` | `https://relay.example.com/v1/chat/completions` |
| `https://relay.example.com/v1/` | `https://relay.example.com/v1/chat/completions` |
| `https://relay.example.com/proxy/v1` | `https://relay.example.com/proxy/v1/chat/completions` |
| `https://relay.example.com/v1/chat/completions` | 保持完整路径 |

上表域名仅为格式示例。填写服务商给的地址即可，脚本自动补全请求路径；无需自行拼接。保存后点击“测试 API 连接”。

支持 HTTPS，以及 `localhost`、`127.0.0.1`、`::1` 的本机 HTTP 服务。地址不能包含用户名、密码、查询参数或片段；不要把 Key 拼进 URL。目前适配 **Chat Completions** 协议，原生 Responses 或 Anthropic Messages 地址需要由中转站转换为兼容接口后使用。

## 不需要填写的参数

Token、temperature 和 thinking 参数已从普通设置中移除。自定义中转站默认不发送厂商扩展字段；若接口明确提示需换用另一种输出长度字段，脚本最多自动修正一次，并按地址及模型记住成功的协议设置，不保存请求正文。鉴权、额度或普通错误不会因此反复请求。

DeepSeek 官方地址固定，不需要修改。模型名需要使用服务商实际提供的名称，脚本不会擅自切换服务商或模型。尝试次数默认 10（包含首轮），通常不需要调整。

## Key 保存与请求通道

Key 保存在本机油猴脚本存储中，不写入源码、发行包或导出的诊断包。每个最终接口地址独立保存 Key 和模型；切换到新地址需要填写该站 Key，不会自动把上一家的 Key 发给新地址。“清除 Key”只清除当前地址的 Key。

模型请求会把文字题目、选项及已判错答案发送给当前选定服务商。优先使用浏览器请求；跨域不可用或特定鉴权失败时，有限尝试油猴请求同一地址，不会切换到其他服务商。油猴若询问连接自定义域名，请核对域名后允许。重定向不作为自动切换接口的手段。

## 常见连接错误

| 提示 | 排查方向 |
| --- | --- |
| 401 | Key 是否由当前服务商签发、是否有效；重新保存后测试 |
| 402 | 账号余额或额度 |
| 403 | 账号权限、模型权限或服务商访问限制 |
| 404 | 服务地址、模型名是否正确 |
| 400 / 422 | 核对服务地址及模型名；仍失败时向服务商确认兼容接口支持情况 |
| 429 | 服务商限流或额度限制，稍后继续 |
| 网络 / CORS | 域名是否可达、油猴是否允许连接、服务是否支持兼容协议 |
| 空回答或无法解析 | 模型是否返回有效的文本答案、输出额度是否足够 |

不要把完整 Key 粘贴到问题反馈、截图或日志中。反馈时提供服务商名称、无凭证接口地址、模型名及错误状态即可。

## 临时记忆与日志

答案只在当前任务、课程、班级和知识点内临时记忆，不读取或识别平台账号。同一知识点多轮重试、刷新及暂停不会清除；达到 100%、放弃或结束任务后清除，不建设长期题库。脚本不主动检测换号，手动换号前应结束旧任务。日志区的“最近送达”才表示收到本机写盘确认，开启日志开关不等于已经送达。容量与判分关联规则见[数据与日志设计](data-and-logs.md)。

## 填空与重试

已适配文本填空输入及页面组件同步，多个空按顺序填写；会记录已判错答案，供后续轮次纠正。优先复用平台解析答案，缺失时调用当前 AI 配置。

支持“AI 无法作答时尝试答案，交卷后收集解析”开关，默认开启。拒答、空回答、格式无效或图片题无法由文字模型识别时，会尝试选择一个选项组合；填空会尝试临时数值。尝试答案必须经过当前题保存确认才会交卷，随后读取平台答案和可用文字解析，后续再使用这些结果。尝试答案不会自行写入已确认正确记忆。关闭开关后，此类情况会暂停。401 等鉴权、额度、网络和保存/交卷状态异常不会触发随机尝试。

每个知识点默认最多 **10 轮（包含首轮）**，可配置 1–10；以平台返回的最高掌握度 **100%** 为完成条件，不用固定全对次数替代。达到轮次上限仍未满分会记录并继续下一点。API 鉴权、保存或交卷结果无法确认时会暂停并弹出提示，避免把未知状态记作完成。

本机日志和调试开关位于“运行日志与诊断”，日常使用无需开启；它们可以独立保存，不会保存尚未确认的接口修改。
