# 当前知识点临时记忆与日志边界

当前交付版本：2.5.7。源码与本版 Release 脚本对齐，既有 v1.0.0 发行附件保留。

原生保存前对父组件的答案绑定最多等待约 1.5 秒。若仍不匹配，但当前题号、实时 DOM 选填值、原生 reviewTopics 子组件及父子归属全部一致，调用原生 chooseAnswer 同步一次，并重新核对实际 DOM 与父组件答案，再保存。没有直接覆盖 userAnswer 或移除校验。新日志 answer.binding-sync 记录题号、题型、方法和数量；answer.binding-mismatch 只记录绑定的类型/空状态，不记录答案内容。

从中间题恢复时，先沿原卷向后核对，到卷末仍有未核对题目则通过唯一原生“上一题”入口回查前题。已保存题按记录版本与实时选填值核验，匹配时不重新调用模型；每题必须在本次遍历中核对，全部题数及保存记录完整才允许交卷。切题最多 `min(200, 2 × 题数 + 2)` 次，超时、入口不唯一或不存在时暂停，不重开卷、不减少题数要求。

填空/简答的保存记录不建立选项 ID 映射，即使原始响应包含非空 `optionVos`。只有选择题按选项 ID 与内容建立映射。2.5.4 在此分支误读不存在的选择题数组，可能在平台保存成功后、写入临时记忆前暂停；2.5.5 修正该分支并保留原卷续接及纠错请求额度。

当前练习页的题目响应另按题号保留最多 128 份页面内缓存，离开对应 URL 或清理当前点时失效；不写入长期题库。选填通过绑定原试卷的原生组件当前题号与 DOM 核对响应，没有原生题号时要求唯一的 DOM 完整匹配，不按最后响应选题。页面题号冲突、相同题干无法唯一辨认或题目版本变化时不填写。保存回执关联核对后的当前题号。填空输入框重建时重新读取当前节点，并核对题目版本、输入结构与实际值。

## 记忆周期与作用域

仅使用一份 `mastery-current-point-v1` 临时会话，内部 schema 为 2，绑定任务 ID、课程、班级及当前知识点。暂停、刷新、同点换卷和页面跳转保持该会话；同一知识点练习到第七轮或更久也不按时间清理。平台确认 100%、放弃该点或明确结束任务时清除题目版本、答案、提交凭据、判分及纠错上下文。

跨知识点只留下队列、实际掌握度、轮次、完成/跳过状态和原因。新任务不会继承上一任务的答案。没有长期题库、答案备份、答案导入导出或同步接口；诊断导出不包含临时记忆。

不读取 Vue 用户资料、不请求用户资料接口、不计算平台账号摘要，也不因缺少 UUID 暂停。旧任务读取时仅移除 account/accountKind，保留任务 ID、原试卷、轮次、已答题目、提交凭据与暂停状态；旧 schema 1 记忆仅在任务/课程/班级/知识点均匹配时升级，答案证据不变。旧暂停任务保持暂停，点击继续后接续原试卷。脚本不检测换号；用户手动换号前应结束旧任务。

兼容处理只删除可明确识别的旧键：`point:<课程>:<班级>:<知识点>:` 下的 `bank`、`usedAnswers`、`rejected`、`explanations`、`trialAnswers`、`rounds` 和 `submitIntent`。API 配置、面板位置、无关设置及任务队列轮次保留。新流程不读取这些旧答案。

## 提交、判分与复用

保存成功后，为本轮试卷实例记录题号、题目指纹、选填结构、实际答案、作答来源和保存确认。交卷前核对题数与最后一题实际状态，并封存本次提交。记录关联任务/课程/班级/知识点作用域、平台试卷编号和本轮实例，不以“最近一次答案”代替。

结果请求在发起时捕获对应提交身份；解析只更新匹配的提交。平台返回实际作答内容时还会核对回显答案；同一平台编号被重复使用时，没有足够回显的迟到结果不用于学习。无法关联、题目版本不匹配或答案回显不一致时不写正确/错误记忆。旧开发版缺少提交凭据的结果，仅可进入平台掌握度核验，不生成答案或连对证据。

判分按试卷实例和结果摘要去重，轮次仍只在平台“去提升”开启一轮时增加，默认最多 10 轮，包含首轮。迟到结果按所属轮次处理，不以到达时间覆盖新证据。若同一答案的新旧证据冲突，保留对应提交的事实；旧错误不能否定后轮已确认正确的答案。100% 始终读取平台实际最高掌握度。

复用指纹包含题干、题型、选项内容版本、媒体及填空结构，不依赖题号或空数。选项排序不影响复用，实际填写时按内容重新映射。填空答案保留大小写、代码符号和前后必要空格。

失败按不同答案去重，完整必要反馈只在本知识点临时会话中保留。AI 请求只包含当前题及最多 3 个相关失败反馈。每题每轮最多 3 次正常或纠正请求，计数跨刷新与暂停保持。鉴权、配置或网络失败不消耗纠正额度。超过纠正上限后，选择题可按设置尝试尚未被判错的组合，填空题会保留原卷并暂停。

## 浏览器日志与送达

- 展示缓存：每页最多 150 条，最近 4 页，只保留阶段、标识、轮次、来源、保存结果、判分和异常原因等运行信息。
- 待发送队列：独立于展示缓存，持久队列最多 600 条或 384 KiB；写入缓冲最多 256 条。超限移除旧项并累计丢失数量，不承诺无限离线补传。
- 收到本机接收器 HTTP 204 后，才按事件 ID 从待发送队列移除；不会清空同时新增的事件。失败或超时保留队列并在 30 秒后尝试，答题流程不等待日志服务。
- 面板显示待发送数量、最近成功送达时间、丢失数及连接/写入问题；开启开关不代表已经成功写盘。
- 默认日志不保存完整题干、选项答案、AI 请求/响应正文或解析正文。展示缓存与本机日志都不作为恢复答案的数据源。

## 本机文件容量

接收器仅监听 `127.0.0.1`，每条被确认的日志先完成文件写入和同步。日志单文件最大 **1 MiB**，含当前文件最多 **4 份**，管理自己的数字后缀轮转文件，最多约 **4 MiB**。

快照仅在必要异常或用户主动诊断时采集，不对正常等待反复抓取。默认只含元素结构、位置和控件类型，删除文本、输入值及可能包含题目的标题属性。每页最多采集 6 份、每份最多 3,000 个元素；接收器按结构摘要去重，单份最多 2 MiB，最多 **6 份且合计不超过 8 MiB**。日志和快照合计管理上限约 **12 MiB**，不含无关文件或调试控制配置。清理只处理接收器能明确识别的文件。

原有接收器进程需要重新启动才能使用新的轮转策略。关闭接收器不影响答题；诊断导出仍可用于查看结构和脱敏运行记录。

## 自动化证据

`tests/test_point_memory.cjs` 覆盖逐次提交、旧结果、重复结果、冲突、版本/选项/空位校验、空格及有界确认队列。

`tests/check_temporary_memory.py` 使用模拟平台跑到第七轮，再暂停、刷新并继续；验证正确答案复用、少量失败反馈、跨页纠正额度、离线与超限、100% 清理、明确结束及旧数据定向清理。`tests/check_course_flow.py` 验证十轮放弃后继续下一点。`tests/check_mastery_entry.py` 验证无 UUID、资料失败或无 ID 时仍答题，且不发送资料请求。`tests/test_no_account_upgrade.cjs` 验证旧提交与记忆迁移隔离。`tests/check_mastery_scope.py` 核对正式考试不注入监听和面板、不读取无关响应正文。原生保存、多题交卷等回归使用隔离夹具。

这些结果属于自动化验证，不代表当前版本已在真实账号验收。历史早期流程曾可用，2.5.2 则有用户确认的账号闸门故障，不能混为一谈。本次没有运行真实课程。
