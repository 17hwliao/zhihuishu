# 智慧树掌握度助手 v1.0.0

用于智慧树 AI 智慧课程的掌握度练习。包含可拖动面板、未满分知识点队列、自动进入练习、答题保存与交卷、结果核验、轮次限制和暂停弹窗。

## 下载与安装

- [直接安装油猴脚本](https://github.com/17hwliao/zhihuishu/releases/download/v1.0.0/zhihuishu-mastery.user.js)：浏览器安装并启用 Tampermonkey 后打开此文件；若浏览器直接下载，可导入油猴或粘贴全文创建脚本。
- [下载完整发行包](https://github.com/17hwliao/zhihuishu/releases/download/v1.0.0/zhihuishu-mastery-v1.0.0.zip)：包含脚本、安装说明、API 配置说明和许可。
- [API 与中转站配置说明](https://github.com/17hwliao/zhihuishu/blob/v1.0.0/docs/configuration.md)。

安装后刷新已登录的 AI 智慧课程页，保存 API 配置并测试连接，开启“进入课程自动启动”或点击“开始本课程”。无需启动 Python 服务。

## 本版功能

- 读取课程掌握度目录，跳过免考及已满分知识点，按队列进入待处理练习。
- 支持选择题和文本填空，优先使用平台解析答案，缺失时调用配置的模型。
- 支持 DeepSeek 官方及自定义 OpenAI Chat Completions 兼容中转站，各地址独立保存 Key 和模型。
- 核对选填状态、当前题保存回执、交卷结果和平台实际掌握度；仅确认 100% 后标记达标。
- 每点最多 1–10 轮，默认 10 轮，达到上限记录未达标并继续下一点。
- 选项状态异常有限自动恢复；需要人工处理时显示暂停弹窗，可查看原因、设置与日志。
- 可拖动并记忆面板位置，提供本机日志与可选调试工具。

## 版本与验证范围

正式发行版本为 **v1.0.0**。为让已安装开发版 2.4.0 的用户正常升级，油猴 `@version` 保持递增为 **2.4.1**；面板显示正式发行版本。名称及命名空间保留，已有本机配置可继续使用。

现有掌握度流程已由用户确认可用；中转站配置及答题状态边界通过隔离自动化检查。未调用用户中转站账号，不保证所有服务商或题目均能达到 100%。此脚本仅处理掌握度，不处理视频、签到或正式考试。图片题缺少题库答案时暂不支持自动回答。

附件 `SHA256SUMS.txt` 可校验脚本、配置说明及 ZIP。源码与附件不包含 API Key、本机日志或个人调试配置。
