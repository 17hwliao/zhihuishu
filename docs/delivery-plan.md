# 掌握度执行链路与交付范围

正式发行版：v1.0.0。安装和中转站配置见根目录 README 与 [API 配置说明](configuration.md)。

## 执行链路

1. 在课程入口、目录、知识点、练习及结果页面加载同一份脚本，识别当前课程和班级。自动模式跨页保存，运行范围绑定当前选定课程。
2. 合并官方目录响应与实际知识点卡片，保持长整数编号精度，区分待处理、满分、免考及异常。面板展示待办清单。
3. 沿知识点“去提升”和掌握度历史页进入平台生成的练习，核对知识点、试卷、题目及题数。
4. 按题型生成答案，写入页面并核对选填状态、Vue 答案绑定与当前题业务保存回执。全卷已保存且题数一致后提交。
5. 读取解析和官方最高掌握度；只以平台返回 100% 标记达标。未满则在轮次上限内继续，达到上限记录未达标后转下一点。
6. 当前课程队列处理完后结束，保留未达标原因。暂停、停止或切课后，旧异步回答不得继续写入。

## 恢复与可观测性

选项更新异常可在同卷有限恢复，持续失败则记录并转下一点。鉴权、保存或交卷状态不明时保留暂停并弹窗提示，避免重复提交或伪报完成。诊断记录脚本构建、页面阶段、题目捕获和业务回执，不记录 Key 或登录凭证。

本机接收器是可选开发工具，关闭后不影响日常运行。源码、安装文件与 Release 附件使用同一构建，发行包附 SHA-256 校验值。

## 已有验证与边界

现有掌握度流程已由用户确认可用。隔离自动化覆盖目录分类、精确编号、两级导航、选择与填空、当前题保存核验、交卷、轮次上限、下一知识点、暂停提示、接口切换、凭证隔离及诊断脱敏。

模拟结果不等于所有真实课程或所有中转站已验收。未调用用户中转站账号；无法保证模型总能答对。缺少题库答案的图片题暂不支持自动回答。此交付仅涉及掌握度，不包含视频、签到和正式考试。
